# Shopify CRO Opportunity Engine — Production Readiness Checklist

This checklist details the steps required to safely deploy the opportunity engine to a production environment.

---

## 1. Environment & Secrets Management
- [ ] Configure `GEMINI_API_KEY` using a production-grade Google AI Studio key.
- [ ] Configure `MONGODB_URI` pointing to a production-ready MongoDB Atlas cluster (with authorization enabled).
- [ ] Ensure `NODE_ENV` is set to `production`.
- [ ] Verify that `.env` is listed in `.gitignore` and never committed.

---

## 2. Infrastructure & Database Operations
- [ ] Verify connection pool limits in `src/server/db/mongodb-client.ts` (`maxPoolSize: 10`, `minPoolSize: 2`).
- [ ] Ensure repository indices are generated by deploying migrations or running initialization scripts (`AuditRepository.initializeIndexes()`).
- [ ] Establish automated Atlas database backups and query performance profiling alerts.

---

## 3. Security Hardening
- [ ] Validate that SSRF protections block private IP ranges (`10.*`, `192.168.*`, `172.16-31.*`) and local loopbacks (`localhost`, `127.0.0.1`, `::1`).
- [ ] Confirm standard security headers are served by Next.js (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`).
- [ ] Place API endpoints behind a rate-limiting gateway (e.g. cloudflare, nginx, or Vercel middleware) to prevent denial-of-service attempts.

---

## 4. Observability & SRE
- [ ] Redirect structured log stdout to a unified logging provider (e.g. Datadog, Logtail, or AWS CloudWatch).
- [ ] Confirm that `requestId` is present on all log entries to correlate extraction, AI processing, and db write phases.
- [ ] Configure latency monitoring and alerts on `/api/v1/analyze` processing speeds.

---

## 5. Build & Validation Pipeline
- [ ] Confirm that `npm run check-types` compiles with `0 errors`.
- [ ] Confirm that `npm run lint` passes with `0 warnings`.
- [ ] Confirm that `npm run test` executes with `100% pass rates`.
- [ ] Run `npm run build` locally to confirm the production Next.js compilation succeeds.
